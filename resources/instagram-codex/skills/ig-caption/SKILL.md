# Textos de publicación · Codex

1. Leer references/ader.md y el pedido actual.
2. Usar como entradas: Pieza, objetivo y datos confirmados. Marcar faltantes; no inventarlos.
3. Redactar el texto que acompaña una pieza. Consultar references/original.md solo como material editorial de referencia, no como reglas de plataforma verificadas.
4. Entregar: Caption breve y una llamada a la acción si aporta. Incluir fuentes y separar evidencia de hipótesis.
5. Revisar precisión técnica, voseo, redundancia y relación con el pedido. Eze conserva aprobación final. No publicar, enviar mensajes ni modificar el bot con esta skill.

## Ejecución en Codex
Se puede invocar por nombre si está instalada; el comando slash de Claude no es requisito. Resolver archivos y scripts respecto de esta carpeta. No depende de Claude, no aporta credenciales ni conexión a Instagram. Guardar trabajo en el proyecto elegido; nunca asumir acceso a una cuenta por tener instalada la skill.

Los scripts originales son herramientas opcionales: revisar su entrada/salida antes de usarlos. Las reglas lingüísticas están principalmente en inglés; sus puntuaciones no validan español, no detectan autoría de IA ni predicen viralidad. No alterar datos para mejorar una puntuación. No inferir causalidad por una métrica aislada. Verificar en fuentes oficiales cualquier límite o política vigente antes de aplicarlo.
