# Instagram para Ader · adaptación a Codex
Origen: https://github.com/Jakeschincariol/instagram-agent-skill
Licencia MIT conservada. Adaptación de 13 skills con instrucciones Ader; originales en references/original.md y utilidades conservadas sin modificar.
Preparado, no instalado en la computadora de Eze. No hay conexión a Instagram ni ejecutor dentro de la oficina.
Para instalación local, copiar las carpetas ig-* de skills a ~/.codex/skills/ y abrir una sesión nueva de Codex. No sobrescribir una versión previa sin revisarla. Invocar por nombre, adjuntar datos y revisar el resultado. La disponibilidad depende del entorno Codex.
Flujo: datos → investigación → brief → borrador → revisión Eze → publicación manual → métricas.
